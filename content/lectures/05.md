**Lecture 5 · Tentative**

[Schedule and materials](../schedule.md)

Backward induction for a task with a fixed deadline, followed by resource constraints, lookahead, and rollout. The main example uses undiscounted rewards and a stated terminal payoff.

## Learning objectives

- Derive the backward recursion and explain why the best action can depend on remaining time.
- Include time or resources in the state and specify feasible actions and terminal conditions.
- Compute a rollout using a base policy and explain when it improves that policy.
