In [Sequential decisions and Markov decision processes](sequential-decisions.md), we described an environment and a policy for acting in it. We now need a way to judge a policy. An action can bring an immediate reward while changing which rewards are available later. A useful evaluation must include both effects.

The **return** adds up rewards along one trajectory. A **value function** averages that return over the trajectories generated by a policy. The **Bellman equations** express these averages recursively: current reward plus the value of what happens next. This recursion is the link between a long sequence of decisions and a calculation involving one transition.

## The model and the policy

We use a finite, nonempty state set $\mathcal X$ and a finite, nonempty set of available actions $\mathcal A(x)$ at each state $x$. At decision $t\geq1$, the agent observes $X_t$, chooses $A_t$, and receives reward $R_t$ and the next state $X_{t+1}$. Thus $R_t$ belongs to the action taken at time $t$; it is not the reward for the next action.

Capital letters such as $X_t$ represent random variables. Lowercase letters such as $x,a,x'$ represent particular possible values. The prime in $x'$ denotes a next state, not a derivative.

The transition model specifies

$$
\mathcal P(x'\mid x,a)=\Pr(\text{next state is }x'\text{ when the input is }(x,a)).
$$

Each transition row contains nonnegative probabilities summing to one. The expected immediate reward is $r(x,a)$. It is the mean of the reward distribution specified by the model at $(x,a)$, even if a particular policy never visits that input.

The Markov assumption says that, given the current state and action, the joint distribution of reward and next state does not depend on earlier observations. We also assume this distribution does not change with time. Reward and next state may be correlated; the assumption does not require their independence.

A general policy $\pi=(\pi_t)_{t\geq1}$ may choose its action using the entire observed history up to time $t$, including earlier rewards. It must be **nonanticipating**: it cannot use future observations. A Markov policy uses only the current state and possibly the time. A **stationary Markov policy** uses the same rule at every decision:

$$
\pi(a\mid x)\geq0,\qquad
\sum_{a\in\mathcal A(x)}\pi(a\mid x)=1.
$$

These probabilities describe the action rule even when the whole history is available. A deterministic stationary policy chooses one action $\pi(x)\in\mathcal A(x)$ with probability one. In the Bellman expectation equations below, $\pi$ is stationary Markov unless stated otherwise.

## From rewards to returns

### Horizon, termination, and discounting

If there are exactly $T$ decisions, the discounted return is

$$
G_1^\pi=\sum_{t=1}^{T}\gamma^{t-1}R_t.
$$

The superscript records which policy generates the trajectory. It does not make the return deterministic: different transitions, rewards, or randomized actions can produce different returns under the same policy.

For a finite horizon, $0\leq\gamma\leq1$ is allowed. At $\gamma=1$, all rewards have equal weight. At $\gamma=0$, only the current reward contributes. For $0<\gamma<1$, a reward $j$ decisions into the future receives weight $\gamma^j$. The discount factor is part of the objective, not an algorithmic step size.

An **episodic task** ends when a terminal state is reached, so $T$ can be random. Here $R_T$ is the final reward and $X_{T+1}$ is terminal. We can represent termination by an absorbing state: a dummy action keeps the process there and all subsequent rewards are zero. The final reward is counted once, and the terminal continuation value is zero. With bounded rewards, finite expected episode length is a sufficient condition for a finite expected undiscounted return. Termination with probability one alone does not ensure finite expected length.

A **continuing task** has no final decision time. From time $t$, its discounted return is

$$
G_t^\pi=\sum_{k=t}^{\infty}\gamma^{k-t}R_k,
\qquad 0\leq\gamma<1.
$$

Assume $|R_k|\leq R_{\max}$. Then

$$
|G_t^\pi|\leq R_{\max}\sum_{j=0}^{\infty}\gamma^j
=\frac{R_{\max}}{1-\gamma}.
$$

The infinite sum is therefore absolutely convergent and its expectation is finite. Without discounting, even a continuing process that gives reward $1$ at every step has an infinite cumulative return. Continuing undiscounted objectives need separate assumptions and analysis; they are outside this chapter.

### Why a finite-horizon value needs a time index

For a finite-horizon Markov policy $\pi=(\pi_1,\ldots,\pi_T)$, define

$$
V_t^\pi(x)=\mathbb E_{t,x}^\pi
\left[\sum_{k=t}^{T}\gamma^{k-t}R_k\right],
\qquad V_{T+1}^\pi(x)=0.
$$

The subscript $(t,x)$ means that we start at decision $t$ in state $x$ and use the remaining policy rules. The discount exponent starts at zero at that decision. The same state can have different values with one decision left and with ten decisions left, so the time index matters. In the resource-allocation example, $t$ identifies the product being considered: the opportunities remaining at resource level $x$ depend on that stage.

With just one decision, only the immediate reward matters:

$$
V_1^\pi(x)=\sum_{a\in\mathcal A(x)}\pi_1(a\mid x)r(x,a)
\leq\max_{a\in\mathcal A(x)}r(x,a).
$$

A probability-weighted average cannot exceed the largest number being averaged. Choosing a maximizing action attains the bound, so randomization cannot improve on it. With several decisions, we must also account for how an action changes future opportunities.

Our main setting from here is a stationary, continuing discounted MDP. Under a stationary Markov policy, starting from $x$ gives the same distribution of future rewards at every decision time. There is no deadline or changing policy rule, so its value can be written $V^\pi(x)$ without a time index.

## State values and action values

Write $\mathbb E_x^\pi$ for an experiment that initializes $X_1=x$ and follows $\pi$. The **state-value function** is

$$
V^\pi(x)=\mathbb E_x^\pi
\left[\sum_{t=1}^{\infty}\gamma^{t-1}R_t\right].
$$

For a history-dependent policy, this definition starts a fresh history at decision $1$. It does not claim that every later visit to $x$ has the same continuation value. The time-independent continuation interpretation below relies on a stationary Markov policy.

For an initial-state distribution $\rho$, the expected return is $\sum_x\rho(x)V^\pi(x)$. Defining the experiment separately at each $x$ also gives values at states with $\rho(x)=0$; we do not condition on an impossible event.

To evaluate a particular first action, use a different experiment: start at $x$, **force the first action to be $a$**, and follow $\pi$ from decision $2$ onward. Its expectation is denoted $\mathbb E_{x,a}^\pi$, and the **action-value function** is

$$
Q^\pi(x,a)=\mathbb E_{x,a}^\pi
\left[\sum_{t=1}^{\infty}\gamma^{t-1}R_t\right].
$$

This definition covers every available action, including actions with $\pi(a\mid x)=0$. The first action is an intervention in the experiment, rather than conditioning an unchanged policy trajectory on an event of probability zero.

$V^\pi(x)$ follows the policy immediately; $Q^\pi(x,a)$ fixes the first action and uses the policy as its continuation. For a stationary Markov policy, averaging the latter over the policy's first action gives

$$
V^\pi(x)=\sum_{a\in\mathcal A(x)}\pi(a\mid x)Q^\pi(x,a).
$$

At $\gamma=0$, $Q^\pi(x,a)=r(x,a)$. For positive discount, the action value also accounts for future consequences. Choosing the largest immediate reward can therefore differ from choosing the largest action value.

## Deriving the Bellman expectation equations

### Separate the current reward from the continuation

The return satisfies the pathwise identity

$$
G_t^\pi=R_t+\gamma G_{t+1}^\pi.
$$

Start the stationary model in state $x$ and follow a stationary Markov policy. If the next state is $x'$, the expected return from the next decision is $V^\pi(x')$. This follows from the Markov property of the environment and the policy: the continuation uses the same model and action rule, and does not need the earlier history.

The **tower property** says that averaging a conditional mean gives the original mean: $\mathbb E[\mathbb E[Y\mid Z]]=\mathbb E[Y]$ for an integrable random variable $Y$ and information $Z$. Using it here gives

$$
\begin{aligned}
V^\pi(x)
&=\mathbb E_x^\pi[R_1+\gamma G_2^\pi]\\
&=\mathbb E_x^\pi[R_1]+\gamma\mathbb E_x^\pi
\left[\mathbb E_x^\pi[G_2^\pi\mid X_1,A_1,X_2]\right]\\
&=\mathbb E_x^\pi[R_1]+\gamma\mathbb E_x^\pi[V^\pi(X_2)].
\end{aligned}
$$

We replace a random future return by its conditional mean and then average over the next state. We are not claiming that the realized future return always equals that mean.

The first term averages the rewards of the policy's available actions. The second averages over an action and then a transition. Therefore

$$
V^\pi(x)=\sum_{a\in\mathcal A(x)}\pi(a\mid x)
\left[r(x,a)+\gamma\sum_{x'\in\mathcal X}
\mathcal P(x'\mid x,a)V^\pi(x')\right].
$$

This is the **Bellman expectation equation** for state values. The policy is fixed throughout. The joint weight $\pi(a\mid x)\mathcal P(x'\mid x,a)$ comes from the probability chain rule, not an independence assumption. Similarly, linearity of expectation lets us add the mean reward and mean continuation without requiring reward and next state to be independent.

### The policy induces a reward vector and a transition matrix

Define

$$
r^\pi(x)=\sum_a\pi(a\mid x)r(x,a),\qquad
\mathcal P^\pi(x'\mid x)=\sum_a\pi(a\mid x)\mathcal P(x'\mid x,a).
$$

Each row of $\mathcal P^\pi$ is a mixture of transition distributions. Once a policy is fixed, there is no remaining action choice in this induced process. Its Bellman equation is

$$
V^\pi(x)=r^\pi(x)+\gamma\sum_{x'}\mathcal P^\pi(x'\mid x)V^\pi(x'),
$$

or, in matrix form,

$$
V^\pi=r^\pi+\gamma\mathcal P^\pi V^\pi.
$$

$V^\pi$ and $r^\pi$ are column vectors in a chosen state order. Matrix rows index current states and columns index next states. Thus matrix multiplication computes the expected next-state value. The rewards and transitions are known model quantities; the value vector is the unknown. The [next note](bellman-operators.md) explains why these equations have a unique solution in the discounted setting.

### The current action is fixed in the action-value equation

For $Q^\pi(x,a)$, take the specified action $a$ first. The current action is fixed; we average its immediate reward and its next-state continuation:

$$
Q^\pi(x,a)=r(x,a)+\gamma\sum_{x'}\mathcal P(x'\mid x,a)V^\pi(x').
$$

Substituting the relation between $V^\pi$ and $Q^\pi$ yields

$$
Q^\pi(x,a)=r(x,a)+\gamma\sum_{x'}\mathcal P(x'\mid x,a)
\sum_{a'\in\mathcal A(x')}\pi(a'\mid x')Q^\pi(x',a').
$$

In the state-value equation, we average the **current action**. In the action-value equation, the current action is fixed and we average the **next action**, after observing the next state.

The slides sometimes write the average of a function $h$ as an integral, for example $\int\pi(da\mid x)h(a)$. For finite actions, this means $\sum_a\pi(a\mid x)h(a)$. The notation says which distribution supplies the weights; it is not a derivative of $\pi$. Transition-kernel integrals have the same interpretation for next-state averages.

## Worked example: evaluate two policies

Consider three states $x_0,x_1,x_2$ and discount $\gamma=0.9$. Only $x_0$ offers a choice:

| Current state | Action | Immediate reward | Next state distribution |
|:---|:---|---:|:---|
| $x_0$ | $a_1$ | $0$ | $0.8$ to $x_1$; $0.2$ to $x_2$ |
| $x_0$ | $a_2$ | $2$ | $1$ to $x_2$ |
| $x_1$ | Sole action | $7$ | $1$ to $x_2$ |
| $x_2$ | Sole action | $2$ | $1$ to $x_0$ |

These are state names, not decision-time indices. Taking $a_1$ at $x_0$ gives reward zero even when the next state is $x_1$. The reward $7$ is obtained on the subsequent action at $x_1$.

Let $\pi_1$ choose $a_1$ on every visit to $x_0$, and let $\pi_2$ choose $a_2$ on every visit. Both take the sole available action elsewhere. In state order $(x_0,x_1,x_2)$,

$$
r^{\pi_1}=\begin{pmatrix}0\\7\\2\end{pmatrix},\qquad
\mathcal P^{\pi_1}=\begin{pmatrix}
0&0.8&0.2\\0&0&1\\1&0&0
\end{pmatrix}.
$$

Reading the Bellman equation row by row gives

$$
\begin{aligned}
V^{\pi_1}(x_0)&=0.9[0.8V^{\pi_1}(x_1)+0.2V^{\pi_1}(x_2)],\\
V^{\pi_1}(x_1)&=7+0.9V^{\pi_1}(x_2),\\
V^{\pi_1}(x_2)&=2+0.9V^{\pi_1}(x_0).
\end{aligned}
$$

Substitute the second equation into the first, then the third:

$$
\begin{aligned}
V^{\pi_1}(x_0)
&=5.04+0.828V^{\pi_1}(x_2)\\
&=6.696+0.7452V^{\pi_1}(x_0).
\end{aligned}
$$

Consequently $V^{\pi_1}(x_0)=6.696/0.2548$. Substitution back into the other equations gives

$$
V^{\pi_1}\approx(26.28,30.09,25.65)^\top.
$$

For $\pi_2$, the induced quantities are

$$
r^{\pi_2}=\begin{pmatrix}2\\7\\2\end{pmatrix},\qquad
\mathcal P^{\pi_2}=\begin{pmatrix}
0&0&1\\0&0&1\\1&0&0
\end{pmatrix}.
$$

Thus

$$
\begin{aligned}
V^{\pi_2}(x_0)&=2+0.9V^{\pi_2}(x_2),\\
V^{\pi_2}(x_1)&=7+0.9V^{\pi_2}(x_2),\\
V^{\pi_2}(x_2)&=2+0.9V^{\pi_2}(x_0).
\end{aligned}
$$

The first and third equations give $V^{\pi_2}(x_0)=3.8+0.81V^{\pi_2}(x_0)$, so

$$
V^{\pi_2}=(20,25,20)^\top.
$$

Under $\pi_2$, starting from $x_0$ never reaches $x_1$. Nevertheless, $V^{\pi_2}(x_1)$ is meaningful: it evaluates a separate experiment initialized there.

Now take $a_1$ once at $x_0$ and follow $\pi_2$ afterward:

$$
Q^{\pi_2}(x_0,a_1)
=0.9[0.8(25)+0.2(20)]=21.6.
$$

By comparison, $Q^{\pi_2}(x_0,a_2)=20$. The action giving the smaller immediate reward has the larger value with this continuation. But $21.6$ is not $V^{\pi_1}(x_0)$: later visits to $x_0$ still use $a_2$. Repeatedly choosing $a_1$ changes the continuation policy and gives approximately $26.28$ instead.

## From policy evaluation to optimal decisions

The example evaluates two policies; it does not by itself establish which policy is best among all possible rules. To formulate that question, let $\Pi_{\mathrm{all}}$ contain all nonanticipating policies, including randomized, time-dependent, and history-dependent policies. Define

$$
V^*(x)=\sup_{\pi\in\Pi_{\mathrm{all}}}V^\pi(x),\qquad
Q^*(x,a)=\sup_{\pi\in\Pi_{\mathrm{all}}}Q^\pi(x,a).
$$

The supremum is the least upper bound. Unlike writing a maximum, it does not assume that a policy attains it. Here, we call a policy optimal if it attains $V^*(x)$ at **every** state. A policy can maximize the average under one initial distribution while performing poorly from states never reached from that initialization. Two arbitrary policies can also be incomparable, with each better at different states.

For finite discounted MDPs, a deterministic stationary policy attains the optimum even against the larger class $\Pi_{\mathrm{all}}$. The Bellman optimality equations characterize its values:

$$
V^*(x)=\max_{a\in\mathcal A(x)}
\left[r(x,a)+\gamma\sum_{x'}\mathcal P(x'\mid x,a)V^*(x')\right],
$$

$$
Q^*(x,a)=r(x,a)+\gamma\sum_{x'}\mathcal P(x'\mid x,a)
\max_{a'\in\mathcal A(x')}Q^*(x',a'),
\qquad V^*(x)=\max_a Q^*(x,a).
$$

These statements require proof. Replacing a policy average by a maximum suggests the right recursion, but does not establish that its solution exists, is unique, or is attainable by one policy. [Bellman operators, fixed points, and optimal policies](bellman-operators.md) supplies those arguments.

The policy interpretation is already useful. If future decisions have value $V^*$, an action is scored by its current reward plus the expected discounted optimal continuation. An optimal action is therefore selected by

$$
\pi^*(x)\in\operatorname*{argmax}_{a\in\mathcal A(x)}
\left[r(x,a)+\gamma\sum_{x'}\mathcal P(x'\mid x,a)V^*(x')\right]
=\operatorname*{argmax}_{a\in\mathcal A(x)}Q^*(x,a).
$$

$\max$ returns the largest numerical value; $\operatorname*{argmax}$ returns the set of actions achieving it. Selecting one maximizing action at each state defines a deterministic stationary rule, with ties resolved consistently.

The same construction defines a **greedy policy** for any candidate $V$ or $Q$, without an optimality superscript. It is greedy with respect to those continuation values, rather than immediate rewards alone. With $V^*$ or $Q^*$, the values already account for the full future, so one local comparison is sufficient. With an arbitrary candidate, that comparison need not produce an optimal policy. In particular, $Q^\pi$ assumes continuation under $\pi$; changing actions on every later visit changes the policy being evaluated.
